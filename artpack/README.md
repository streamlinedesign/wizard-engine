# Wizard Engine art pack

Everything the game needs drawn, with exact sizes, so an Aseprite file set up
from this list drops into `assets/` with no code changes. Style is the agreed
"style B" (see `docs/ASEPRITE.md`): 16x16 tiles, characters about 2.5 tiles
tall, a muted cool palette, soft grey outlines on characters and props, no
outlines on terrain.

Files in this folder:

- `palette.gpl`: the palette. In Aseprite: Palette menu (the ≡ next to the
  palette) > Load Palette, pick this file. Add colours freely; these are the
  anchors.
- `guides/`: PNG guide sheets at real size for the character cell, the
  effect cell and the autotile layout. Open one, add a layer above it, draw,
  hide the guide layer before export (or just draw in a fresh file with the
  grid settings below; the guides are there to show the lines).

## Aseprite setup, once

- Sprite size and colour mode: RGBA.
- View > Grid > Settings: width and height per the table below (16x16 for
  tiles, 16x40 for characters, 32x32 for effects). Snap to grid on.
- Edit > Preferences > Export: uncheck "Trim", leave rotation off.
- Save the `.aseprite` sources in `art/` (not in `assets/`); only exports
  go to `assets/`.
- This folder is regenerated by `make artpack`; edit the palette in
  `tools/mkartpack/main.go`, not in `palette.gpl`.

## Export, every time

File > Export Sprite Sheet, or from a terminal:

```
aseprite -b art/wizard.aseprite \
  --sheet assets/sprites/wizard.png --data assets/sprites/wizard.json \
  --format json-array --list-tags --sheet-type packed
```

Tilesets and icons are plain PNGs (File > Export As); no JSON needed.
Animated things (characters, creatures, effects) need the JSON.

## The pack, in the order the game needs it

### 1. The player wizard (first; on screen every second)

| What | Size | Count | Tag names |
|---|---|---|---|
| Cell | 16 wide x 40 tall, feet on the bottom row (row 39), centred | | |
| Walk | 4 frames per direction | 12 | `walk_down`, `walk_up`, `walk_side` |
| Idle | 1 frame per direction (can be frame 0 of walk: tags may overlap) | 3 | `idle_down`, `idle_up`, `idle_side` |
| Cast | 4 frames per direction, staff raised, release on frame 2 | 12 | `cast_down`, `cast_up`, `cast_side` |
| Hurt | 2 frames, one direction is fine | 2 | `hurt` |
| Meditate | 4 frame loop, sitting | 4 | `meditate` |

`side` faces **right**; the engine flips it for left. Frame duration 140 ms
for walk, 100 ms for cast. Head about 8 px tall, hat above it, so a 40 px
cell has room for a tall hat. Keep the feet at the same pixel in every
frame so he does not slide. Suggested layout: one row per tag, 4 columns.

Later, clothing layers (hat, cape, robe) are separate sheets with the same
cell and the same frames, drawn over the base body; draw the base in
plain underclothes with that in mind.

### 2. The old wizard and other NPCs

Same cell and tags as the player: `idle_*` (3) and `walk_*` (12). A small
`talk` tag (2 frames, a nod or a hand gesture) is nice but optional.
NPCs in order: old wizard, scribe, librarian, students (3 variants share
one body with different hair and robe colours), merchants.

### 3. Portraits

32x32 each, one per named character, drawn as a bust facing slightly
left. Used in the dialogue box. One PNG per character, or one sheet in a
`portraits.png` grid with 32x32 cells.

### 4. Campus tileset

16x16 cells, one PNG, any number of columns (8 is tidy). Ground tiles
opaque; props transparent where the ground shows through. Keep tile ids
stable: add new tiles at the end, never reorder.

**Ground (autotiled; draw the 47-tile blob set for each)**

- Grass (also used under everything)
- Stone path / cobbles
- Plaza flagstones
- Water (4 frames of animation: export as four 47-tile sets side by side)

The blob layout is in `guides/autotile_blob.png`: 47 tiles that cover
every combination of edges and inner corners. If that is too much to
start, draw the 16-tile set (edges only, no inner corners) and we upgrade
later.

**Single tiles**

- Grass variants: worn, flowers, with a stone, with a mushroom (4)
- Dirt, gravel (2)
- Stairs up/down, cliff edge set: top, bottom, left, right, 4 corners (10)
- Building kit: wall, wall with timber, wall top band, roof (2 colours),
  roof ridge, roof edge left/right, chimney, door (closed, open), window,
  window lit (14)
- Tower pieces: round wall, round roof cap (4)
- Props 16x16: lamp (lit, unlit), bench, signpost, fence (straight, post,
  corner), hedge, barrel, crate, well top, flower bed, mooring post, notice
  board (14)
- Props 16x32 (two cells stacked, the engine splits them): tree (3 kinds),
  lamp post tall, statue, fountain centre (6)
- Props 32x32: fountain basin, market stall, boat at anchor, boatyard
  cradle, moon altar (5)
- Dock planks, pier edge (3)

### 5. Interiors tileset

16x16, one PNG. Floors (wood, stone, rug centre + rug edges), interior wall
with top band, doorway, bookshelf (3 variants), desk, lectern, chair, bed,
alchemy bench, cauldron, bottle shelf, enchanting table, display case,
pinball cabinet (16x32), battleship table (32x32), fireplace (16x32, 3
frames lit).

### 6. Item icons

16x16 cells in `assets/icons/items.png`, 10 columns. Existing order, keep
it: 1 empty scroll, 2 bound scroll, 3 fireball, 4 minor heal, 5 minor
teleport, 6 barrier, 7 grimoire, 8 coin, 9 thunderstrike, 10 gust of wind.
Then add: staff (3 tiers), ring, cape, crystal ball, hat, boots, amulet,
lucky coin, candle, rosemary, 6 herbs, 6 potion bottles (same bottle,
colour swapped), empty bottle, blood vial, tarot card back, 4 tarot faces,
fish (6), fishing rod, boat blueprint, wood log, cloth, crystal, ore,
Head of Medusa, Hydra scale. Icons have a 1 px outline and sit inside a
14x14 area so they never touch the cell edge.

### 7. Spell effects

32x32 cells, 8 columns, transparent background, one row per effect, in
`assets/effects/<name>.png` + JSON. Frame duration 60 ms unless noted.

| Effect | Frames | Tag | Note |
|---|---|---|---|
| Fireball, flying | 4 loop | `fly` | pointing right; the engine rotates |
| Fireball, impact | 6 | `hit` | |
| Heal | 8 | `self` | plays on the caster |
| Thunderstrike | 6 | `strike` | bolt comes from above the cell; impact at the bottom centre |
| Gust | 6 | `self` | swirl around the caster |
| Barrier | 3 appear, 4 loop, 3 break | `appear`, `hold`, `break` | 48x48 cell for this one |
| Teleport out / in | 5 + 5 | `out`, `in` | |
| Generic hit flash | 3 | `hit` | white, used by everything |
| Dust puff (footstep) | 4 | `puff` | 16x16 cell |

Element variants (water, air, earth, light, dark) are recolours of the
fireball pair to start.

### 8. Creatures

Same rules as characters, cell sized to the creature: training dummy
16x32 (idle 1, hit 2, fall 4), slime 16x16 (idle 4, move 4, hit 2, die 4),
bat 16x16 (fly 4, die 4). Bosses later at 48x48 or 64x64; same tags plus
`attack_*`.

### 9. UI

- Panel frame: 9-slice, 24x24 image with 8 px corners (`ui/panel.png`).
  The middle tile repeats. Parchment fill, dark timber edge.
- Font: `ui/font.png`, 5x7 glyphs in 6x8 cells, ASCII 32 to 126 in that
  order, 16 columns (so 6 rows). Second file `ui/font_title.png`, 8x12
  glyphs in 9x13 cells, same order.
- Icon strip `ui/icons.png`, 8x8 cells: heart, mana drop, luck clover,
  coin, moon (8 phases), clock, lock, star, warning, arrow (4).
- Cursor 8x8, selection corner 4x4, bar end caps 3x6.
- Grimoire page background 420x220, two pages with a spine.

### 10. Later (do not start yet)

Winter village tileset (snow versions of 4 and the props), weather
particles (snow 4x4, rain 2x8), moon phase set 16x16 x 8, ships (64x32
and up), bosses.

## Rules that save rework

- Feet on the bottom row of the cell, always; the engine positions by
  feet.
- Every frame of a tag is the same cell size.
- Transparent background; no baked shadows (the engine draws a shadow
  disc).
- Side views face right.
- Do not anti-alias against transparency; hard edges only.
- Keep the `.aseprite` sources; export is one command and can be redone.
